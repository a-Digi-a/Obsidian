#programming/C #computing 

# Char

A char is a single character. It takes a single byte (8 bits) of memory. E.g. 'a'.
# Int

An int stores a negative or positive integer value. It takes 8 bytes and can store numbers from -2,147,483,648 to 2,147,483,647

# Float

A float stores a floating-point number i.e. a decimal. It takes 4 bytes and stores values from approximately 7 digits x E-38 to E+38

# Double

A double can store floating point numbers with higher accuracy and takes 8 bytes instead of four.
