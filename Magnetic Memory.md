# Magnetic Memory

Magnetic materials have **domains**. These are essentially 'mini magnets' which are aligned in random direction when in the absence of a magnetic field, meaning the material is **not magnetised**. 

When an external magnetic field is applied, the domains **align** and the material becomes **magnetised**.
