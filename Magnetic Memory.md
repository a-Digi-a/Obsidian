# Magnetic Memory

Magnetic materials have **domains**. These are essentially 'mini magnets' which are aligned in random direction when in the absence of a magnetic field, meaning the material is **not magnetised**. 

When an external magnetic field is applied, the domains **align** and the material becomes **magnetised**.
![[Pasted image 20260120111633.png]]

If we **magnetise** a material, then remove the magnetic field, it **remains magnetised**

This is called **magnetic memory**

The material must be **forced** back to its original state with **a magnetic field in the opposite direction**

## Hysteresis Loop

If an **alternating magnetic field** is applied to a material, its magnetisation will trace out a **hysteresis loop**

Different properties of materials result in **different hysteresis curves**, making them useful in different situations

![[Pasted image 20260120112342.png]]

A material with a **wide** hysteresis curve is considered **magnetically hard**
A material with a **narrow** hysteresis curve is considered **magnetically soft**
