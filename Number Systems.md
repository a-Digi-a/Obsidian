# Number System Basics

A number system is determined by its **cipher**, which is how high of a number it takes for you to have to add another. e.g. in decimal, you can count up to 10 before you need to use 2 places. In hexadecimal, it is 16.

In order to find the value of a place in a number system you raise the cipher to the power of its place. The number to the left of the decimal point is place 0, the one to the left of that base 1, etc. The reverse is true to the right of the decimal point starting at -1, -2, etc.
